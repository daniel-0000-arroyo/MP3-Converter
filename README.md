Un simple pero efectivo descargador de canciones a .mp3 sin necesidad de anuncios.
Tan simple que se ejecuta en terminal.
Sin necesidad de abrir paginas web desde el navegador, ni descargando archivos dudosos.

¿Como usarlo?

- Simplemente descarga y descomprime el repositorio (el app.py y el ffmpeg, que es necesario para funcionar).

- Introduce los datos de la API en el script.

- Inicia el script y elije entre las dos opciones.

- Disfruta de la descarga de canciones.
